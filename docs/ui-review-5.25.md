# Version 5.25 UI確認

## 変更

- 上部に画面名を表示し、スクロール中もヘッダーを固定。
- 冒険者の詳細を標準の開閉要素にまとめ、初期状態を閉じる。
- 今日の任務を冒険者の直後に配置し、毎日クエストへ進むボタンを追加。
- タブごとにスクロール位置を保持。同じタブを再度押すと先頭へ移動。
- 下部ナビのサイズと選択状態を統一。選択中の画面をaria-currentでも示す。
- 動きを減らす端末設定に合わせて画面切り替えアニメーションを停止。

## 画面と操作の確認

1. ホーム：変更前は冒険者の詳細が最初の画面をほぼ占有していた。変更後は320×568でも今日の任務ボタンを下部ナビより上に表示。
2. 冒険者の情報：開くと既存の称号・タイプ・進化情報を表示し、再度押すと閉じる。
3. 今日のクエストへ：毎日クエストを選択して先頭に移動。
4. タブの移動：クエストをスクロールし、成長を経由して戻ると位置を復元。ホームでも595pxの位置復元と再タップでの先頭復帰を確認。
5. 保護者確認：ギルドを選ぶと従来のPIN入力画面へ移動し、ギルドを選択状態にする。

319pxの直接プレビューに加え、iframeで320×568、375×667、390×844、768×1024、1280×800のレイアウトを確認。横はみ出しと表示中画像の読み込み失敗なし。

## 検証範囲

ローカルの確認用データを使用し、Firebase接続・サービスワーカー登録をプレビューサーバーで止めて確認した。このサーバーと認証を省略する処理はリリース対象に含めない。実ユーザーの進捗や認証処理は変更しない。

自動テスト12件が成功。実機Safari、画面読み上げ、ソフトウェアキーボード表示中の配置、実ユーザーの長い名称やふりがな設定での網羅的な検証は未実施。
